1、顶点着色器（Vertex Shader）
	顶点着色器是几个可编程着色器中的一个；
	--*如果打算做渲染，现代OpenGL需要我们至少设置一个顶点和一个片段着色器*；
2、OpenGL的着色器语言GLSL
	用着色器语言GLSL（OpenGL Shading Language）编写顶点着色器，然后编译这个着色器；
```GLSL
以下是非常基础的GLSL顶点着色器的源代码

#version 330 core
layout (location = 0) in vec3 aPos;

void main()
{
	gl_Postiton = vec4(aPos.x, aPos.y, aPos.z, 1.0f);
}
```

> [!tip] 顶点着色器的GLSL源代码
> `#version 330 core`
> > 每个着色器都起始一个版本声明；OpenGL 3.3以及和更高版本中，GLSL版本号和OpenGL的版本是匹配的（比如：GLSL 330版本 对应 OpenGL 3.3）；同时明确表示会使用核心模式；
>
>`layout (location = 0) in vec3 aPos;`
> - 使用`in`关键字，在顶点着色器中声明所有的输入顶点属性（Input Vertex Attribute）；
> - `vec3`：GLSL向量类型，3个`float`分量：`x`，`y`，`z`，存储三维顶点坐标；
> - `aPos`：变量名，前缀`a`代表attribute（顶点属性）；
> - `layout (location = 0)`：**属性位置编号**，这个`0`就是 CPU 调用
> `glVertexAttribPointer(0, ...)`对应的索引；
> > 注意：CPU就是靠这个`location`编号，把`VBO`里的数据绑定到着色器的输入变量上；
